Software and operating systems

Summary

This lecture showed how computer software is organized. System software (programming languages, compilers and interpreters, operating systems) runs the computer, while application software is what people use directly. An operating system sits between the user and the hardware and manages memory, the processor, devices and files. The lecture also covered types of operating systems and the three main families: Windows, Macintosh and Unix-like.
